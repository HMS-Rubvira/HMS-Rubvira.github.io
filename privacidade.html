Política de privacidade do rubvira-upload

Última atualização: 23 de novembro de 2026.

O rubvira-upload é uma ferramenta pessoal usada apenas pelo dono do canal Rubvira Games para gerenciar o próprio canal do YouTube.

Dados acessados

Com a autorização do dono do canal, o app usa a YouTube Data API para enviar vídeos, definir título, descrição, tags, miniatura, playlist e visibilidade dos vídeos do próprio canal. Nenhum dado de outros usuários ou espectadores é coletado.

Armazenamento e compartilhamento

A autorização (token) fica guardada só no computador do dono do canal. Nenhum dado é enviado a terceiros, vendido ou usado para publicidade.

O uso de dados recebidos das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

Revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
